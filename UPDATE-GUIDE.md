# Where to update the website

1. Name, email, LinkedIn, calendar link, resume: edit `profile.js` (open it on GitHub, click the pencil icon, edit, then Commit changes).
2. Headline, intro text, services, toolkit tabs, project cards, About, credentials: edit `index.html`. Use Ctrl+F to find the text you want to change.
3. Colors, fonts, spacing: edit `styles.css`.
4. Behavior (tabs, filters, contact buttons): `app.js`. Usually no changes needed.
5. To add a resume: upload `resume.pdf` to this repository and set resume: "resume.pdf" in `profile.js`.

Changes go live about 1 to 2 minutes after each commit.

Before sharing: confirm the 1 million and 120 million record migration figures, the Windows services / Windows Forms cards under C# / .NET, your years of experience, and certification wording.
